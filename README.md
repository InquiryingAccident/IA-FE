## 비행기 사고 기록 조회 앱

#### 만든 배경

- 만든 시기 : 2025년 1월경
- 비행기 사고가 많이 발생하지만, 이를 구체적으로 확인할 수 있는 앱이 없었음.
- 처음에는 중고차 어플 같은 비행기 부품 조회 기능도 넣으려 했으나, 해당 자료들은 항공사 극비자료 임에 따라 자료를 얻을 수 없어 해당 기능 구현 불가능

#### 기능

- 항공편을 입력하면 해당 비행기에 사용된 비행기종과 해당 항공기 넘버를 통해 사고기록 조회 가능
- 주의할 점은 항공기 사고는 사고가 큰 경우가 대부분이므로, 항공기 넘버를 통해 조회하는 방식은 대부분 재운행 불가능 하다는 점이 있음

#### 사용 기술 스택

- 서버 자체 회원가입 및 로그인(email방식)
- 소셜 로그인 기능 도입 -> 닉네임 자동화 배정 기능 구현, 추후 변경 가능
- zustand와 react query(tanstack query)를 사용한 클라이언트-서버 상태 관리
